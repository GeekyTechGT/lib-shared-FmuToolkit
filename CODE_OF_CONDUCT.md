# Code of Conduct

## Purpose

`your_library` is maintained as a professional engineering scaffold.
Collaboration is expected to remain technical, respectful, and traceable to observable facts.

## Expected Conduct

- discuss code, architecture, tests, packaging, and release behavior with evidence
- keep reviews concrete, reproducible, and scoped to the change under discussion
- document assumptions when changing API, ABI, install layout, preset behavior, or registry assets
- raise regressions, security concerns, and release risks promptly
- keep the scaffold generic and reusable

## Unacceptable Conduct

- harassment, discrimination, threats, or intimidation
- personal attacks, hostile sarcasm, or deliberately adversarial review behavior
- concealing breaking changes in public API, binary outputs, package metadata, or install layout
- bypassing documented release, packaging, or security controls without maintainer approval

## Enforcement

Maintainers may edit, reject, or revert contributions and may suspend repository access when conduct or process violates this policy.
