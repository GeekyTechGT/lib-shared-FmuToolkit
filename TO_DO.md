# Roadmap

## Completed Baseline

- installable CMake package scaffold with shared and static outputs
- multi-compiler CMake preset matrix
- vcpkg registry templates, overlay triplets, and consumer documentation
- example application, tests, Docker image, and Windows helper scripts
- zero-touch source and test auto-discovery under `src/` and `tests/`

## Next Candidates

- add optional CI examples for more compiler families
- add additional example topologies for larger libraries
- add more guidance for converting the placeholder scaffold API into a real library surface
