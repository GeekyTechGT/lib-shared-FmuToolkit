# FmuToolkit - Specifications

Functional and technical specifications for FmuToolkit live here, one file
per feature or component (e.g. `export-report.md`).

| Folder / file | Content |
|---|---|
| `*.md` | Specifications: goal, scope, requirements, acceptance criteria |
| `jira/` | Material exported from or linked to Jira issues (epics, stories, attachments), one file or folder per issue key |

Architecture-level decisions do not belong here - record them in
[`../adr/adr.md`](../adr/adr.md).
